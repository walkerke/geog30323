# GEOG 30323 — Data Analysis and Visualization (Fall 2026)

Course materials for GEOG 30323 at Texas Christian University, taught by
[Kyle Walker](https://walker-data.com). 

## Structure

- `slides/` — Quarto revealjs lecture decks (TCU theme in `slides/_extensions/tcu/`)
- `notebooks/` — course assignment notebooks (Google Colab / Jupyter)
- `data/` — curated course datasets
- `GEOG30323-015_Fall2026_Walker.pdf` — the course syllabus

Materials from earlier editions of the course (2015–2024) are archived at
[walkerke/geog30323-legacy](https://github.com/walkerke/geog30323-legacy).
